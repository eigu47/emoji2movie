## Emoji2Movie

Simple movie guessing game where emoji hint at film titles.

- **Stack**: Next.js, React (server components), Tailwind, Shadcn, Drizzle ORM (SQLite locally / Turso remotely), and OpenAI via the Vercel AI SDK for generating the emoji hints.
- **Try it!**: [eiguchipablo.dev/emoji2movie](eiguchipablo.dev/emoji2movie)
